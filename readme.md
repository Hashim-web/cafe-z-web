# ☕ Cafe-Z — Restaurant Ordering Web App

A full-stack web application built with **Flask** and **SQLite** that allows users to browse a restaurant menu, add items to their cart, place orders, and view order history.

## 🚀 Features
- Dynamic menu display (Fast Food & Drinks categories)
- Add-to-cart functionality using Flask sessions
- Order checkout with customer name
- Orders saved permanently in SQLite database
- Order history page (view all past orders)
- Styled with custom CSS for a clean, professional UI

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** HTML, Jinja2 templating, CSS

## ⚙️ How to Run Locally
```bash
git clone https://github.com/Hashim-web/cafe-z-web.git
cd cafe-z-web
pip install -r requirements.txt
python Cafe-z_web.py
```

Then open `http://127.0.0.1:5000` in your browser.
